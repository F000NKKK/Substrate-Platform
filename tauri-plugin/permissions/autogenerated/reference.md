## Default Permission

Every command Substrate's UI calls.

#### This default permission set includes the following:

- `allow-open-url`
- `allow-open-path`
- `allow-reveal-path`
- `allow-dir-list`
- `allow-dir-create-file`
- `allow-dir-create-dir`
- `allow-dir-rename`
- `allow-dir-remove`
- `allow-dir-copy`
- `allow-file-read`
- `allow-file-write`
- `allow-allow-path`
- `allow-fs-watch`
- `allow-git-status`
- `allow-git-stage`
- `allow-git-unstage`
- `allow-git-discard`
- `allow-git-commit`
- `allow-git-last-message`
- `allow-git-diff-texts`
- `allow-git-head-text`
- `allow-git-log`
- `allow-git-commit-files`
- `allow-git-branches`
- `allow-git-switch`
- `allow-git-branch-create`
- `allow-git-branch-delete`
- `allow-git-remote`
- `allow-git-integrate`
- `allow-git-operation`
- `allow-git-clone`
- `allow-git-init`
- `allow-git-stash-list`
- `allow-git-stash-push`
- `allow-git-stash-op`
- `allow-git-config-get`
- `allow-git-config-set`
- `allow-find-in-files`
- `allow-find-cancel`
- `allow-replace-in-files`
- `allow-project-items`
- `allow-project-files-containing`
- `allow-workspace-load`
- `allow-workspace-save`
