# substrate-message

Substrate's shared kernel: the user-facing `Message`, an English template with
`{name}` placeholders, and the `messages!` macro that declares a module's
templates.

**Layer and context:** shared kernel · message

- For: everything Substrate says to a user. The English template is the key the
  UI's translation catalogs use; the values travel beside it.
- Not for: errors. Each context owns its typed error enum and turns it into a
  `Message` once, at the interface.
- Not for: the TypeScript copy of the templates; that is generated by
  `substrate-host-contract`.

## Usage

```rust
use substrate_message::Message;

let message = Message::new("{path} already exists").arg("path", "/a");
assert_eq!(message.to_string(), "/a already exists");
assert_eq!(Message::verbatim("raw").to_string(), "raw");
```

## Depends on / used by

Depends on nothing in the workspace. Used by
every context's domain crate (each declares its templates
with `messages!`), [`substrate-host-contract`](../substrate-host-contract/README.md)
and [`tauri-plugin-substrate`](../../tauri-plugin/README.md).
